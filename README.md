# Image Forensics / Photo Inspector

تطبيق مفتوح المصدر لتحليل الصور محليًا قدر الإمكان باستخدام C# و.NET MAUI، مع Android كمنصة أساسية وقابلية إضافة Windows لاحقًا.

## المبادئ
- Offline-first وحماية الخصوصية.
- عدم رفع الصور تلقائيًا.
- فصل الحقائق المؤكدة عن الاستنتاجات الاحتمالية.
- قراءة آمنة للملفات وعدم تنفيذ أي payload.
- عدم الحكم القطعي على أن صورة "أصلية" أو "مزورة" من مؤشر واحد.

## الحالة
بدأ التنفيذ من المجموعة 0: تأسيس المشروع والهندسة، ثم الانتقال تلقائيًا لبقية المجموعات حتى Release.

## Target
- .NET 10
- .NET MAUI Android
- Arabic RTL first
- Dark / Light
- CI عبر GitHub Actions
